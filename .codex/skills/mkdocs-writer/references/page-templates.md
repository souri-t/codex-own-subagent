# Page Templates

必要なときだけ、この雛形を出発点にすること。

## 目次ページ

```md
# <文書名>

## 概要

この章で扱う対象を 2 から 4 行でまとめる。

## 一覧

| ID | 名称 | 概要 |
|----|------|------|
| X001 | 項目名 | 1 行で説明 |

## 補足

- 必要なら前提や読み方を書く
```

## API 詳細ページ

````md
# API-XXX <API 名>

## 概要

| 項目 | 内容 |
|------|------|
| メソッド | `POST` |
| パス | `/resources` |
| 説明 | API の役割を 1 行で書く |

## リクエスト例

```json
{
  "example": "value"
}
```

## レスポンス例

```json
{
  "result": "ok"
}
```

## バリデーション

- 必須項目
- 形式制約
- エラー条件
````

## 画面詳細ページ

```md
# SXXX: <画面名>

## 画面レイアウト

![](<diagram-file.drawio>)

## レイアウト

- 上部領域
- 主領域
- 補助操作

## 操作イベント

- 主操作
- 遷移
- 更新契機
```

## 機能一覧ページ

```md
# 機能仕様

## 機能一覧

| 機能ID | 機能名 | 概要 |
|--------|--------|------|
| F001 | 機能名 | 1 行で説明 |

## 機能詳細

### F001: 機能名

- 入力条件
- 出力結果
- 処理概要
```

## 共通仕様ページ

```md
# 共通仕様

## 共通ルール

| 項目 | 仕様 |
|------|------|
| 項目名 | 内容 |

## 共通ヘッダー

| ヘッダー名 | 必須 | 内容 |
|------------|------|------|
| `Header-Name` | Yes | 説明 |

## 制約

- 命名規則
- 型やフォーマット
- 省略時の扱い
```
